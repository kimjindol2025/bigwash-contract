# 2026-07-21 WashCare 5주차 CarePlan Admin 체크포인트

## 이번 작업

- `GET /care/care-plans`를 무필터로 호출하면 고객·현장명을 포함한 최신 50건을 반환하도록 확장했다.
- 연간관리 Admin 화면에 전체 목록, 상태 필터, 가입, 사용횟수 절대값 정정, 취소와 갱신 기능을 연결했다.
- 고객 상세에 활성 플랜명과 잔여 방문 횟수 요약, 연간관리 탭과 현장별 가입 폼을 추가했다.
- 새 A/S 접수에서 현장 ID를 입력하면 활성 CarePlan과 종료일·잔여 횟수를 안내하도록 했다.
- 정수 입력 검증, 중복 제출 방지, 비동기 응답 순서 보호와 티켓 상세 XSS 방어를 보강했다.
- README, API 문서, OpenAPI와 구현 일정표를 현재 동작에 맞춰 동기화했다.

## 중요한 결정

- 티켓 화면의 CarePlan 정보는 안내 전용이며 할인·과금·방문 자동차감·접수 차단을 수행하지 않는다.
- 전체 목록만 최신 50건으로 제한하고, `site_id` 또는 `customer_id`가 있는 기존 목록은 해당 범위를 그대로 반환한다.
- 상태 표시와 필터는 저장 상태가 아니라 서울 날짜 기준 `effective_status`를 우선한다.
- 결제 상태, PG 연동과 미수금은 PaymentOrder 및 운영 게이트가 확정될 때까지 제외한다.

## 검증 기준

- FreeLang 테스트 10종 전체 통과
- Admin 인라인 JavaScript 문법 검사 통과
- 구현과 OpenAPI의 JSON API 라우트 53개 일치
- 무필터 CarePlan 목록 200, 잘못된 정수 필터 400, Admin 페이지 200 실제 HTTP 확인
- `git diff --check` 통과
- 운영 DB `db/contracts.sqlite`는 커밋 대상에서 제외
