# 2026-07-21 WashCare 1~3주차 체크포인트

- Orca 새 작업 트리의 의존성 설치, 환경 파일 복사, 격리 DB 마이그레이션 절차를 `orca.yaml`에 구성했다.
- 코드와 문서를 대조해 README, 실행 가이드, API 문서와 OpenAPI 명세를 현재 구현에 맞췄다.
- 운영 대시보드에 지연, 일정 미정, 오늘 방문, 보증 만료 임박 집계를 추가했다.
- 주간 운영 보고에 신규 접수, 완료, 미처리, 다음 주 방문, 다음 주 점검 임박 집계를 추가했다.
- 대시보드와 주간 보고의 경계 조건, 서울 시간대, 최대 50건 목록 제한, 입력 검증을 자동 테스트로 고정했다.

## 중요한 결정

- 개발 중에는 API 키가 없는 요청도 허용하지만 실데이터와 외부 공개 환경에는 배포하지 않는다.
- 일정 미정은 담당자 컬럼을 임의로 만들지 않고, 열린 티켓 중 `scheduled_at`이 없는 항목으로 정의한다.
- 주간 미처리는 완료·취소가 아닌 접수·일정·진행 중 티켓 전체로 정의한다.
- 미수금과 PG 연동은 결제 주문 모델과 법적·운영 게이트가 확정될 때까지 제외한다.
