# 디자인 레퍼런스 — SMART경리 (회계·수금 모듈 참고자료)

작성일: 2026-07-20

> 이 문서는 제공된 디자인 목업 이미지(`SMART경리` — 세무회계사무소 대상 정산·매출
> 관리 앱) 한 장을 화면별로 분해해 기록한 **레퍼런스 문서**다. 이 색상·레이아웃을
> 대한이엔지 시스템에 그대로 적용하겠다는 결정이 아니라, `docs/07-company-system-menu.md`
> 9번 "회계·수금" 모듈을 실제로 설계할 때 참고할 완성도 높은 정산 대시보드 사례로
> 남겨둔다. 이 시스템 자체의 실제 시각 규칙은 저장소 루트 `design.md`(어두운
> indigo·주황 팔레트)가 정본이며, 이 문서는 그것을 대체하지 않는다.
>
> 원본 이미지는 하나의 세로 목업 시트이며, 아래는 그 안에 포함된 개별 화면을
> 순서대로 나눠 기록한 것이다. 색상 값은 목업을 육안으로 판독한 근사치이며,
> 실제 구현 전 원본 디자인 파일(Figma 등)이 있다면 그 값으로 재확인해야 한다.

## 0. 제품 인상

- 세무·회계 사무소가 고객사(거래처)의 매출·매입·정산 현황을 관리하는 B2B
  업무용 앱. PC(대시보드형)와 모바일(카드 스택형) 두 폭을 모두 지원하는
  반응형/투플랫폼 설계.
- 색상 대비가 뚜렷한 **보라색 브랜드 아이덴티티**가 전체를 관통한다 — 스플래시,
  헤더, 주요 버튼, 차트 포인트 색이 전부 같은 보라 계열로 통일.
- 숫자(매출·매입·정산액)가 화면의 절대적 주인공이다. 카드마다 금액을 가장
  크고 굵게 배치하고, 증감을 빨강(지출·마이너스)과 보라(수입·플러스)로
  구분한다.
- PC는 "한눈에 보는 대시보드" 성격이 강하고, 모바일은 그 대시보드를 스크롤
  가능한 카드 스택으로 재구성한 형태 — 정보 구조는 동일하고 레이아웃만
  플랫폼에 맞게 바뀐다.

빨강/보라 2색 대비가 이 시스템의 핵심 규칙이다 — "나가는 돈(매입·지출)은
빨강, 들어오는 돈(매출·정산 예정)은 보라"로 색이 곧 의미를 전달한다. 새
색상을 추가할 땐 이 이분법을 깨지 않아야 한다.

## 2. 타이포그래피

- 화면 제목("이번달 정산 현황" 등): 굵게, 본문 대비 1.3~1.4배 크기
- 통계 카드 금액: 가장 큰 글자 크기 + 굵게, 카드 안에서 시각적으로 압도적인
  비중을 차지
- 통계 카드 라벨("매출", "매입"): 금액보다 작고 연한 회색, 금액 위 또는 옆에
  배치
- 리스트 항목(거래처명·항목명): 중간 크기, 금액은 오른쪽 정렬로 같은 행에 배치
- 보조 텍스트(날짜, 필터 조건): 가장 작은 크기, 회색

## 3. 간격과 레이아웃

### PC 대시보드

```text
┌─────────────────────────────────────────────┐
│ 상단바 (보라 배경, 로고 + 메뉴 + 우측 유틸)      │
├───────┬───────────────────────────────────────┤
│       │  섹션 타이틀 + 기간 필터(우측 드롭다운)   │
│ 사이드 │  ┌───────────┬───────────┐             │
│ 바     │  │ 통계 카드1 │ 통계 카드2 │             │
│ (화이트│  │ (빨강/지출)│ (보라/매출)│             │
│  배경, │  └───────────┴───────────┘             │
│  아이콘│  ┌───────────────┬───────────────┐     │
│ +텍스트│  │  막대그래프     │  도넛차트+범례   │     │
│  메뉴) │  └───────────────┴───────────────┘     │
│       │  ┌───────────────┬───────────────┐     │
│       │  │ 거래처 TOP 리스트│  오늘 일정/공지  │     │
│       │  └───────────────┴───────────────┘     │
└───────┴───────────────────────────────────────┘
```

- 사이드바는 좁은 고정폭, 화이트 배경, 아이콘+텍스트 메뉴를 세로로 나열
  (이 저장소의 `washcare-admin.html` 사이드바 그룹핑 패턴과 개념적으로 유사 —
  다만 SMART경리는 그룹 라벨 없이 플랫 리스트)
- 본문은 카드 그리드: 2열(통계 카드), 2열(차트), 2열(리스트) 구조가 반복
- 카드 모서리는 큰 라운드(대략 12~16px급), 카드 사이 여백은 넉넉하게

### 모바일

```text
┌─────────────────┐
│  보라 헤더 (타이틀) │
├─────────────────┤
│  통계 카드 (세로 스택)│
│  ┌─────────────┐ │
│  │  빨강 카드    │ │
│  └─────────────┘ │
│  ┌─────────────┐ │
│  │  보라 카드    │ │
│  └─────────────┘ │
├─────────────────┤
│  차트 카드         │
├─────────────────┤
│  리스트 카드        │
└─────────────────┘
```

- PC의 2열 그리드가 모바일에서는 완전한 1열 세로 스택으로 풀린다 — 화면마다
  주제 하나(정산 현황 / 매출·매입 추이 / 카드 지출 분석+TOP 거래처 / 오늘
  일정 / 세금계산서 리스트)만 담당하도록 화면 자체를 쪼갠다(PC는 한 화면에
  다 모아두지만, 모바일은 화면을 나눔).

## 4. 컴포넌트 규칙

### 상단바 / 헤더 (PC·모바일 공통 보라 배경)

- PC: 가로 전체 폭, 좌측 로고, 중앙 또는 우측에 메뉴/검색, 우측 끝에 알림·
  프로필
- 모바일: 화면 제목만 담은 좁은 헤더, 뒤로가기 아이콘 포함 가능

### 통계 카드(핵심 컴포넌트)

- 두 가지 색 변형만 존재: **빨강(지출/매입 계열)**, **보라(수입/매출 계열)**
  — 세 번째 색을 새로 만들지 않는다
- 카드 안 구성: 상단에 작은 라벨(예: "이번 매입"), 중앙에 큰 금액, 카드
  우측 상단에 작은 아이콘(원형 배경)
- 카드는 항상 2개가 한 쌍(지출/수입 대비)으로 붙어 나온다

### 차트 패널

- 막대그래프: 다채색(보라·핑크·옐로우·블루) 막대, 카테고리 또는 일자별 비교
- 도넛차트: 중앙에 합계 금액 텍스트, 우측 또는 하단에 색상 점 + 항목명 +
  금액 범례 리스트

### 리스트 카드

- 각 행: 좌측 항목명(거래처명 등) + 우측 정렬 금액, 행 사이 얇은 구분선
- "TOP 리스트"류는 금액 내림차순 정렬이 기본 규칙으로 보임

### 배지 / 상태 표시

- 오늘 일정·공지 항목에 작은 색 점 또는 배지로 긴급도/유형 구분(구체 색상
  판독 어려움 — 구현 시 이 시스템 기존 배지 규칙 재사용 권장)

## 5. 화면 인벤토리 (목업에 포함된 전체 화면)

### PC (3개 변형 — 같은 대시보드의 레이아웃 실험으로 보임)

1. 기본형: 사이드바 + 통계 카드 2개 + 막대그래프 + 도넛차트 + 거래처
   TOP리스트 + 우측 보조 패널
2. 상단바 보라색 버전: PC 변형 1과 동일 구성이나 최상단에 보라색 통합
   메뉴바 추가(로고+검색+메뉴+로그인 상태)
3. 컴팩트형: 변형 2와 유사하되 카드·차트 배치를 더 좁은 폭에 맞게 압축

### 모바일 (스플래시 → 로그인 → 홈 4종 → 리스트)

1. **스플래시**: 보라 단색 배경 전체, 중앙에 로고(아이콘+"SMART경리" 워드마크)
2. **로그인**: 화이트 배경, 상단에 사업장/회사 선택 드롭다운, 아이디·비밀번호
   입력 필드, 하단 로그인 버튼(보라)
3. **홈 – 이번달 정산 현황**: 보라 헤더 + 매출/매입 통계 카드 2개(빨강/보라
   세로 배치)
4. **홈 – 일별 매출/매입 현황**: 동일 헤더 + 막대그래프 카드(기간 필터 포함
   추정) + 하단에 매출·매입 합계 요약
5. **홈 – 신용카드 지출분석 + 거래처 TOP리스트**: 도넛차트 카드 + 거래처
   순위 리스트를 한 화면에 결합
6. **홈 – 오늘 일정**: 리스트형, 항목별 배지·아이콘으로 일정 유형 구분
7. **세금계산서 / 거래명세서 리스트**: 문서 유형별 리스트, 각 행에 거래처명·
   금액·상태로 추정되는 구성

## 6. 이 시스템(대한이엔지)에 적용 시 고려할 점

- 이 문서의 보라/빨강 팔레트를 저장소 루트 `design.md`의 기존 indigo/주황
  팔레트에 그대로 얹지 않는다 — `design.md` "절대 하지 말 것" 8번(팔레트 밖
  임의 강조색 금지) 원칙과 정면으로 부딪힌다. 회계·수금 모듈을 실제로 만들
  때는 **기존 팔레트 안에서 "지출=적색(`--color-red-500`, 현재 미사용
  선언값), 수입=주황/초록"** 식으로 재해석해야 한다.
- 다만 **레이아웃·정보구조**(통계 카드 2분할 대비, 차트+리스트 2열 그리드,
  모바일에서 화면을 주제별로 쪼개는 방식)는 색상과 무관하게 `docs/07` 9번
  회계·수금 모듈, 특히 1번 "홈" 대시보드 설계 시 그대로 참고할 가치가 있다.
- "거래처 TOP 리스트" 개념은 `docs/05-customer-management-design.md` 17장
  고객 등급·매출 집계와 사실상 같은 데이터(고객별 매출 합산 정렬)이므로,
  회계 모듈에서 새로 설계하지 않고 그 로직을 재사용할 수 있다.
