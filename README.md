# BigWash Contract System

계약 관리 시스템 - FreeLang v11로 구현

## 기능
- 계약서 생성 및 관리
- 계약 상태 추적
- 견적서 연동
- 계약금 관리

## 기술 스택
- FreeLang v11
- SQLite
- REST API

## 폴더 구조
```
├── src/              # FreeLang 소스 코드
│   ├── contract.fl   # 계약 관리 로직
│   ├── db.fl         # DB 스키마
│   └── api.fl        # API 엔드포인트
├── tests/            # 테스트
├── docs/             # 문서
└── db/               # SQLite 데이터베이스
```
